## How To Use This Brand Kit

Treat the files in this folder as the source of truth for all branded work.

Before creating any website, landing page, ad, social graphic, presentation, document, email, video asset, print piece, UI, mockup, or AI generated visual:

1. Read `2 - Brand Guidelines.md`
2. Read `3 - Visual Identity.md`
3. Read `4 - Brand Voice.md`
4. Read `5 - Messaging.md`
5. Read `6 - Brand Context and Prices.md` when pricing, services, offers, products, geography, or operating details matter
6. Use only approved assets from `/assets`
7. Do not redraw, recreate, reinterpret, or approximate the logo
8. Do not invent colors, fonts, services, claims, pricing, certifications, locations, guarantees, or business facts
9. When a source file and a general convention conflict, the source file wins

## Priority Order

1. Current approved brand assets
2. This brand kit
3. Existing website or production materials
4. Approved campaign references
5. General design conventions

## Non Negotiable Rules

- Use the official logo assets only
- Never redraw or approximate the logo
- Preserve logo proportions
- Follow documented clear space and background rules
- Use approved colors only
- Use the documented type hierarchy
- Match the documented imagery style
- Match the documented brand voice
- Use approved claims and factual business information
- Do not fabricate testimonials, credentials, pricing, statistics, awards, locations, staff, or guarantees
- Do not introduce visual trends that conflict with the brand
- Do not default to generic AI aesthetics
- Favor consistency over novelty

# AI IMAGE GENERATION RULES

When creating new images for this brand:

1. Use supplied reference photos when identity accuracy matters
2. Use official logos only
3. Do not ask the image model to redraw the logo if an official asset can be composited later
4. Keep uniforms, vehicles, equipment, locations, and signage factually correct
5. Follow the documented photography and color treatment
6. Preserve recurring brand visual cues
7. Avoid generic stock aesthetics
8. Avoid fake small text when it will be visible
9. Create each asset for its actual final aspect ratio
10. Maintain subject continuity across a campaign when requested
